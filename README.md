# NotaFiscal Project

This project is a simple invoice processor with a React frontend and a Node.js backend.

## Project Structure

```
.
├── backend/
│   ├── package.json
│   ├── server.js
│   ├── .env
│   └── uploads/
├── frontend/
│   ├── package.json
│   ├── public/
│   │   └── index.html
│   ├── src/
│   │   ├── App.js
│   │   ├── App.css
│   │   └── components/
│   │       └── InvoiceProcessor.js
│   └── tailwind.config.js
└── README.md
```

## Getting Started

### Backend

1.  Navigate to the `backend` directory:
    ```sh
    cd backend
    ```

2.  Install the dependencies:
    ```sh
    npm install
    ```

3.  Start the server:
    ```sh
    npm start
    ```

### Frontend

1.  Navigate to the `frontend` directory:
    ```sh
    cd frontend
    ```

2.  Install the dependencies:
    ```sh
    npm install
    ```

3.  Start the React development server:
    ```sh
    npm start
    ```
